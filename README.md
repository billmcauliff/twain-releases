# Twain releases

Signed builds of [Twain](https://github.com/billmcauliff/twain), a small macOS Markdown reader and editor, and the Sparkle update feed (`appcast.xml`) that installed copies check.

Download the latest `Twain-<version>.zip` from [Releases](https://github.com/billmcauliff/twain-releases/releases), unzip it, and move `Twain.app` to Applications. Later versions install themselves.
